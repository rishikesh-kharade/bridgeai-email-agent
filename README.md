#  BridgeAI Email Agent

An AI-powered Email Management System built using **Python** and **FastAPI**.

---

##  Project Overview

BridgeAI Email Agent is an intelligent backend application that automates email processing using Artificial Intelligence and Gmail APIs.

The system is designed to:

- Summarize Emails
- Classify Emails
- Generate AI-powered Replies
- Extract Tasks
- Schedule Calendar Events
- Manage Notifications

This project is being developed as part of the **BridgeLabz AI Engineering Assessment** with a focus on scalable backend architecture and clean software engineering practices.
